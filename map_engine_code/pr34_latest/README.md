# juicytea-media
Juicy Tea Shorts media

Standing owner rule, in order: (1) ready-made assets from the hub (`ASSET_HUB.json` and `asset_library/`); (2) if missing, a free web asset with commercial use and no attribution (CC0, public domain, OFL for fonts), downloaded and logged with its license and source; (3) build it yourself only when neither exists, and say what you checked. See `ASSET_HUB.md` and `pipeline/README.md`. Re-fetch the hub at the start of each episode. Private packs are for rendered video only and are never committed.
