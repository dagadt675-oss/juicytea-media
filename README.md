# juicytea-media
Juicy Tea Shorts media

Standing owner rule: use ready-made assets from the hub (`ASSET_HUB.json` and `asset_library/`) for icons, 3D pins, vehicles, characters, face parts, animations, Lottie FX, textures, and fonts. Build from scratch only when nothing suitable exists, and then say which entries you checked and why they did not fit. Re-fetch the hub at the start of each episode. See `ASSET_HUB.md`. Private packs are for rendered video only and are never committed.
