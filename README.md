# juicytea-media
Juicy Tea Shorts media

Standing asset rule for every episode: use the asset hub first, then a commercial-use no-attribution download (CC0 or public domain), and build geometry only if both fail. Never use CC-BY, NC, ND, or game/brand IP. Anything downloaded from the web is appended to `assets/FOUND_ASSETS.md` (and, under 50 MB and redistributable, saved in `assets/found/`) so it can be mirrored into the shared Drive hub. The full rule is in `whatif/scale_journey/README.md`.
