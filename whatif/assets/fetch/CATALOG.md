# JuicyTea CC0 3D Asset Library — CATALOG

Built 2026-10-11 on the box. Root: assets_cc0/<category>/<pack>/. One zip per category (assets_cc0_<category>.zip).

Total CC0 library size (uncompressed): 3.51 GB.
**License rule:** every pack in the CC0 zips is CC0 1.0 (Kenney, Quaternius, Poly Haven, ambientCG) or NASA public domain. No attribution required for YouTube use (crediting Kenney/Quaternius/Poly Haven/ambientCG in the description is a nice courtesy). Items marked CC-BY on poly.pizza were excluded. Engine-specific folders (Unity/Godot/Unreal projects, .unitypackage) were dropped; where a pack had glTF/GLB, duplicate OBJ (and FBX unless animated) exports were dropped.

## ANIMATIONS

See animations/ANIMATIONS_INDEX.md for every clip name, rig type and retarget notes (Quaternius UAL1+UAL2 = 86 clips on the Universal rig incl. idle/walk/jog/sprint/crouch/jump/sit/swim/death/roll; CMU BVH mocap 74 clips; animated dogs/fox/wolf/horses in animals/quaternius_ultimate_animated_animals; Kenney cube-pet cat/dog; animated fish; tanks). Private (no-redistribute) Sketchfab Free Standard + BlendKit animations incl. #gags dances are in the PRIVATE zip only.

## PRIORITY: People (rigged/animated) and Trees

**People:** characters/quaternius_universal_base_characters (rigged bases, multiple body types/skins, hairstyles) + quaternius_universal_animation_library 1&2 (walk/run/idle/sit etc., same rig); quaternius_ultimate_modular_men/women + animated_men/women (stylized animated GLB pedestrians with outfits); kenney_mini_characters, kenney_blocky_characters (stylized animated), kenney_animated_characters_* (FBX + idle/run/jump). No kids/elderly-specific CC0 sets found besides outfit variety; see BlendKit PRIVATE zip for realistic people incl. children/elderly. Mixamo was NOT used (not CC0; Adobe terms).

**Trees:** nature/quaternius_stylized_nature_megakit (best stylized canopies: common/birch/pine/twisted/dead), quaternius_ultimate_nature (150: birch, pine, willow, palm, common, dead + autumn and snow variants, bushes), quaternius_textured_stylized_trees, quaternius_ultimate_stylized_nature, kenney_nature_kit (low-poly trees incl. palms/pines/autumn), polyhaven_trees_rocks (semi-real). Previews: Preview.png/jpg in each Quaternius pack, Previews/ per-model PNGs in Kenney kits, previews/ JPG per model for poly.pizza-sourced packs, preview.png per Poly Haven asset.
