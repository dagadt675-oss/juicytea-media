# Found assets

Standing rule. Every model, texture, HDRI, addon, or sound effect downloaded from the web (not already in the asset hub) is appended here on the PR branch, then mirrored into the shared Drive hub.

Hub packs are not listed again. They already live in `ASSET_HUB.json`.

Each new row needs:

| Field | What to write |
| --- | --- |
| Name | File name as saved |
| Download | Direct file URL |
| Source | Page the file came from |
| License | CC0 or public domain only. No CC-BY, NC, ND, or brand IP |
| Size | Bytes |
| For | Which episode or shot it is for |
| File | `assets/found/<name>` when the file is under 50 MB and redistributable. Larger files stay out of git; this row is still required |
